# Emad Logo - Android Studio project

هذا مشروع أولي لتطبيق أندرويد:
- اختيار صورة من الاستوديو.
- إضافة شعار عماد الهاشم على الصورة.
- التحكم بحجم الشعار.
- حفظ النتيجة في Pictures/EmadLogo.

## إنشاء APK
1. افتح المشروع في Android Studio.
2. انتظر انتهاء Gradle Sync.
3. من القائمة اختر Build > Build APK(s).
4. ستجد APK غالباً في app/build/outputs/apk/debug/app-debug.apk.

ملاحظة: هذا أرشيف مصدر المشروع وليس ملف APK جاهزاً. يحتاج Android Studio/Android SDK لبنائه.
